lol_char_projesi

özelikler
-Rastgele bölge seçimi
-Rastgele rol seçimi
-Rastgele şampiyon seçimi
-Kurtardın/Kurtaramadın
-Kazanınca şampiyon serbest kalır / Kaybedince kilitli kalır 
Kulanılan teknolojiler
-Python/pygame-ce
